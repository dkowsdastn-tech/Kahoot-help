# Winner AI для iPhone

В режиме «Камера» Safari снимает экран ведущего. Gemini читает видимый вопрос и варианты и показывает предполагаемый ответ. При смене кадра запускается новый анализ. Для мелких изменений есть повторная проверка. Скорость зависит от интернета и ответа Gemini. Игра открывается отдельно через официальный QR ведущего или на kahoot.it. Для одновременной игры и режима камеры используйте ещё одно устройство. На одном iPhone возможен режим скриншотов, если на экране игрока виден вопрос.

## Размещение на Render

1. Распакуйте ZIP и загрузите его содержимое в корень собственного репозитория GitHub.
2. В Render выберите **New → Blueprint** и подключите репозиторий. Настройки запуска уже есть в `render.yaml`. Если обновляете существующий сервис, загрузите файлы в его подключённый репозиторий и выполните Deploy последнего коммита.
3. Укажите новый `GEMINI_API_KEY` в настройках окружения. `APP_PASSWORD` задаётся в окружении сервиса. Blueprint генерирует его автоматически. Откройте **Environment**, чтобы посмотреть значение или задать своё. Передавайте пароль только тем, кто будет пользоваться помощником.
4. После статуса Live откройте HTTPS-адрес сервиса в Safari на iPhone. Введите пароль приложения.
5. На одном устройстве войдите в Kahoot по QR ведущего. На iPhone с помощником нажмите «Включить автоанализ», разрешите камеру и наведите её на экран ведущего так, чтобы текст занимал большую часть кадра. Сверяйте распознанный вопрос с текущим перед выбором варианта.
6. Для режима на одном iPhone сделайте скриншот вопроса, переключитесь в Winner AI и выберите фото. Для этого ведущий может включить показ вопросов и вариантов у игроков.

## Локальный запуск

Node.js 22. Установите переменные окружения `GEMINI_API_KEY` и `APP_PASSWORD`, затем запустите `npm start`. Демо открывается без ключа. Для доступа к камере с iPhone нужен HTTPS. Скриншот или видимый кадр отправляется Google для анализа.

Если ключ Gemini ранее был отправлен в чат, отзовите его в Google AI Studio и создайте новый. Сам ключ остаётся в окружении сервера. В браузере вводится только пароль приложения.
